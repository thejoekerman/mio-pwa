# Review Drafting and Recommendations

## Review Drafting

- Server review drafting is optional.
- Local review drafting uses on-device WebLLM/WebGPU when supported.
- Draft language follows the App language.
- Review drafts target the explicitly selected Journey.

## Recommendations

- Backlog recommendations are local deterministic ranking, not AI.
- Recommendation reasons must be true by construction and derived from local structured data.
