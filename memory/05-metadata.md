# Metadata and Covers

- Metadata assistance is App-owned and user-confirmed.
- Wikidata/Wikipedia suggestions help fill canonical metadata without touching Journey fields.

## Duplicate Protection

- No unattended bulk metadata cleanup or fuzzy matching across an imported spreadsheet library.
- Duplicate protection uses external identity when available and offers to add a new Journey to an existing Game or deliberately create a separate Game.

## Covers

- Cover storage and caching are provider-neutral.
- Users may continue using existing IGDB image URLs as ordinary cover URLs.
- Legacy server enrichment data was intentionally removed after preserving the selected cover and displayed developer/publisher values.
