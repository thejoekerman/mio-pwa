# MioLog Trademark and Brand Policy

The MioLog name, MioLog logos, Mio/Mio-chan character artwork, app icons, social
preview art, official domain identity, and related visual branding are brand
assets of Tony / the MioLog project owner.

The AGPL license covers the source code. It does not grant permission to use
MioLog branding in a way that confuses people about who runs or endorses a fork,
hosted copy, package, or service.

## You May

- Refer to this project as MioLog when accurately describing the original
  upstream project.
- State that your project is a fork of MioLog.
- Use the included assets while developing or testing an unmodified local copy of
  this project.

## You Must Not

- Present a fork, hosted copy, package, app store listing, container image, or
  service as the official MioLog app unless you have written permission.
- Use the MioLog name, logos, Mio/Mio-chan character assets, or
  official-domain-like branding in a way that suggests endorsement by the project
  owner.
- Register domains, social accounts, package names, or container images that are
  likely to confuse users into believing they are official MioLog properties.

## Fork Guidance

If you publish a modified version, give it a distinct name and replace the
MioLog-specific branding. A clear note such as "Forked from MioLog" is welcome
when it does not imply official status.
